# KGL Backend API Server

Karibu Groceries Limited (KGL) Backend Assignment

## Overview
This project is a fully functional Express.js backend API developed for Karibu Groceries Limited (KGL).

It provides a system for:

Managing procurement records

Recording cash and credit sales

Handling staff authentication and user roles

The server is connected to MongoDB and follows a modular architecture using separate routers.

## Technologies Used

Node.js

Express.js

MongoDB + Mongoose

JWT Authentication

Swagger API Documentation

dotenv (Environment Variables)

bcrypt (Password Hashing)
